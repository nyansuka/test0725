UMANOTE

構成計画書

JRA 全レース・全券種の高配当候補を、短時間で見極められるサイトをつくる。

最終更新 2026-07-25　／　Next.js + Docker

01 / 目的

何をつくるか

  • JRA の全レースを対象に、各券種で配当が閾値以上の候補を選別
  • 関係馬が 1〜3着に入る可能性があるものを短時間で見極められる構成
  • 本命探しではなく、高配当候補の選別を第一機能とする
  • 地方競馬（NAR 等）は対象外
02 / 確定方針

4つの決定事項

01 オッズゲートの券種

すべての券種（単勝・複勝・枠連・馬連・ワイド・馬単・3連複・3連単）

02 オッズ閾値

変更可能。初期デフォルト 20倍。設定 UI を早期に用意

03 スコア

当面はルール＋仮スコア。将来差し替え可能な設計にする

04 対象レース

JRA 全レースのみ（中央競馬）。地方競馬は含まない

未確定（後続）

データソース（サンプル継続 or 外部取込）／券種別の表示優先度

03 / 成功の定義

「選別できる」状態

#条件
A券種ごとに「オッズ ≥ ユーザー設定閾値」の候補を一覧できる
B候補に紐づく馬の「1〜3着ポテンシャル」をスコア／ランクで見られる
Cなぜ候補にしたかの根拠（短評・指標）が表示される
D当日の JRA 全レース横断で、候補をまとめて確認できる
Eオッズ閾値（および最低スコア）を画面上で変更できる

※ 実馬券の的中保証は対象外。デモ／検証用の選別ロジックとして扱う

04 / プロダクト方針

コア価値と境界

やること

  • フィルタ　閾値未満は原則除外
  • 評価　人気薄でも複勝圏に届くか数値化
  • 範囲　JRA 10場のみ
  • 提示　レース・当日横断・券種の3軸

やらないこと（初期）

  • 自動投票・資金管理
  • 地方競馬データの取り込み
  • リアルタイム高頻度更新
  • 機械学習の本番運用
05 / 選別ロジック

Hard Filter — 全券種

候補単位は「馬」だけでなく 券種 × 買い目

candidate.odds >= oddsThreshold   // 初期値 20
candidate.betType ∈ JRA全券種
candidate.race.authority === "JRA"
  • win単勝
  • place複勝
  • bracket_quinella枠連
  • quinella馬連
  • wideワイド
  • exacta馬単
  • trio3連複
  • trifecta3連単
05 / 選別ロジック

Soft Score — placePotential

各馬に 0〜100 のスコア。当面は説明可能なルール＋仮実装

指標例（仮）

コース適性／脚質×展開／馬場状態／枠・騎手／前走内容／人気との乖離

表示条件

odds ≥ oddsThreshold
AND relatedPlacePotential ≥ scoreMin
AND race.authority === "JRA"

oddsThreshold

20

倍（変更可能）

scoreMin

60

点（変更可能）

05 / 出力ラベル

候補のラベル案

注目穴

閾値以上かつ relatedPlacePotential 上位

抑え候補

閾値以上かつ relatedPlacePotential 中位

見送り

ゲート通過でもスコア不足（詳細では表示可）

組み合わせ券の評価

  • 単勝/複勝 → 対象馬の placePotential をそのまま使用
  • ワイド/馬連 → 2頭の合成（初期は平均 or 下限）
  • 3連系 → 3頭の合成（将来変更可）

06 / 注目穴ボード

最重要画面の設計

1行の表示項目

  • 会場 / R / 発走時刻
  • 券種・買い目・オッズ
  • relatedPlacePotential（バー）
  • 短評（1文）＋詳細リンク

操作

  • ソート: スコア / オッズ / 発走順
  • フィルタ: 会場・芝ダート・券種・閾値
  • 閾値変更はボード上 or /settings と同期
07 / データモデル

ドメインの中核型

Race / Horse

authority は常に JRA。各馬に placePotential と factors。oddsBoard で券種別オッズを保持

LongshotPick

raceId × betType × selection × odds × relatedPlacePotential × label

UserSelectionSettings

oddsThreshold (20) / scoreMin (60) / enabledBetTypes

選別関数

selectLongshots(races, settings): LongshotPick[]

UI は生データ直接判定せず、この結果のみ表示
